# Contributing Guidelines

Thank you for contributing to the Repo Intelligence Platform!

## Development Workflow

1. **Fork & Branch:** Create feature branches from `main`.
2. **Build Composite Packages:** Run `npm run build` (`tsc -b`) to compile all TypeScript packages.
3. **Run Vitest Tests:** Ensure `npx vitest run` passes 100% of test suites.
4. **Linting:** Run `npm run lint`.
5. **Submit PR:** Submit clean Pull Requests with descriptive titles.
